Ask my portfolio

Ask a question about my experience or projects. The page retrieves the most relevant passages from a small set of documents and answers only from them, citing each source. If the documents do not cover the question, it says so.

What this is. The retrieval half of a RAG pipeline, running without a server: chunking, a BM25 keyword index and answers assembled from retrieved sentences. The full project in the repository uses OpenAI embeddings in Qdrant for retrieval and an LLM to write the answer, behind a FastAPI service. No language model runs on this page.
